# Wild Secrets Studio

A free, faceless AI wildlife YouTube Shorts production studio. Enter a
topic, get a full package: title, hooks, timestamped script, scene
breakdown, AI image + image-to-video prompts, thumbnail, SEO, captions, and
an optional voiceover.

See the main [README.md](README.md) for full usage instructions.

**Note on this Space:** storage here is ephemeral — the SQLite project
history resets on a Space restart/sleep. For persistent local use, run the
app on your own machine instead (see the main README).
