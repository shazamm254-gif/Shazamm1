# Wild Secrets — Your First 10 Shorts (ready to produce)

Ten complete, ready-to-shoot Shorts across all five pillars in
`tools/niche-wildlife.json`, generated with the system prompt in
[`WILDLIFE_AI_SYSTEM_PROMPT.md`](WILDLIFE_AI_SYSTEM_PROMPT.md). Every fact
below is real and traceable to published research — see the note under each
Short's script.

**How to read each script:**
- **HOOK (0–2s)** — exact words on screen + said aloud in frame 1.
- **ON-SCREEN** — big text (most people watch muted first).
- **VO** — full voiceover, 45–60s. Narrate calm, precise, awestruck — a BBC
  Earth narrator who can't quite believe what they're describing either.
- **SCENES** — 4 shots to generate and cut on, ~10–15s apart. Each has an
  **AI image prompt** (paste into Midjourney / Flux / Leonardo, set to
  **vertical 9:16**) and an **image-to-video prompt** (paste into Runway /
  Kling / Luma to animate that still).
- **END** — the loop line or question (drives re-watch + comments).
- **TITLE / DESC / TAGS** — paste-ready. Run through
  `tools/optimize_metadata.py` before posting.

Narration target: ~2.5 words/second. A shared visual language carries across
all 10: **photorealistic, 8K, wildlife documentary, vertical 9:16, shallow
depth of field, natural light, BBC Earth / National Geographic color grade.**
Keep that phrase block in every prompt so your channel's grid looks
consistent.
