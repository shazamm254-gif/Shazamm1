# Herbs Decoded — Paste-Ready Image Prompts (4 shots × 10 Shorts)

Copy each prompt block into your image tool (written and tested for
descriptive-prompt models like Nano Banana / Gemini image generation — they
work in Midjourney, Flux, Leonardo too). Set **vertical 9:16**, generate 3–4
variations per shot, keep the best. The channel style is written into every
prompt, so all your clips match automatically.

**The channel look (baked into each prompt):** vivid botanical color glowing
against a near-black background, one soft directional light, macro detail.
Photographic shots share one style tail; diagram shots share another — your
grid stays consistent either way.

Pair each set with the matching script in `FIRST_10_SHORTS_HERBAL.md`
(same numbering). Cut every 1.5–3 seconds; shot order follows the voiceover.

## Tips for descriptive-prompt models (Nano Banana / Gemini)

- Paste the block as-is — these models respond best to full natural-language
  descriptions, no keyword tricks needed.
- If a diagram comes out with garbled text, add "absolutely no text, no
  letters, no numbers" to the end of the prompt. On-screen words get added in
  your editor, never in the image.
- For a matching custom thumbnail, re-run the Short's strongest shot and add:
  "extra negative space in the top third of the frame" — that's where your
  3–4 word overlay goes.
- Keep the near-black background line in every prompt you write yourself —
  it's what makes the channel grid read as one brand.
