# Extreme Weather What-Ifs — Visual Pack (Ember Edition)

> **Two visual editions exist for these scripts.** This is the **ember edition**
> — warm, kinetic, spectacle-forward: you shoot the event itself. The
> [**aftermath edition**](VISUAL_PACK_WEATHER_AFTERMATH.md) shoots the same 5
> scripts cold and still, in the Death channel's memento-mori language, framing
> the residue instead of the disaster. Pick one per video, or A/B them — the
> aftermath file ends with a recommendation on which scripts suit which.

Shot-by-shot AI image/video prompts for all 5 scripts in the Extreme Weather
full-voiceover pack. Copy a prompt, append the **master style suffix**, add your
9:16 flag, and generate. Every shot lists its edit timing and a motion note for
video generators (Runway / Kling / Pika / Veo).

> Generate 3–4 variations per shot and keep the most *menacing* one. Cut every
> 1.5–3 seconds. The first frame of Shot 1 doubles as your thumbnail unless a
> dedicated thumbnail prompt is listed.

---

## The master style suffix (append to every image prompt)

```
cinematic disaster documentary, photorealistic, ultra-detailed, volumetric
storm light, single dramatic light source, deep contrast, muted desaturated
palette with one hot accent color, subtle film grain, awe-inducing scale,
ominous mood, 8k, dark documentary aesthetic
```

**Example (Midjourney):**
```
A wall of heat shimmer rising off an empty suburban street at noon, mirage
warping the houses, cinematic disaster documentary, photorealistic,
ultra-detailed, volumetric storm light, deep contrast, subtle film grain,
awe-inducing scale, ominous mood, 8k --ar 9:16 --style raw
```

**Aspect ratio:** Midjourney `--ar 9:16` · Flux/Leonardo/DALL·E 1080×1920 ·
Runway/Kling/Pika: vertical preset.

**Channel accent color:** ember orange (#FF5A1F) — the one hot color against a
muted world. Use it for on-screen text and let it echo the fire/heat in frame.

## Batch workflow

1. Generate all 20 prompts in one sitting (3–4 variations each) so the look
   stays consistent — same suffix, same session, same model version.
2. Animate only shots that need motion (hooks and payoffs first) — stills with
   a slow digital push-in read fine for mid-script beats.
3. Keep every clip 1.5–3s in the edit; land the on-screen text with Shot 1.
4. First frame rule: Shot 1 must read clearly at phone-lockscreen size — if you
   can't tell what it is in 0.3 seconds, regenerate it.
